# T04 main review follow-up

After the initial T04 implementation/tests complete, address these concrete review points within the original T04 scope. Read latest actual source first; no recursive delegation, no git/plan/other task edits. Update t04-result.md and rerun check.sh when fixed.

1. `TranscriptEditor.split` and `subdividingTurns` currently use unknown boundary Word time `?? original/turn.startUs/endUs`. That can manufacture a known timestamp for a newly split segment whose only Word has null time. Derive a newly created speech segment's range from its own timed Words; if it has no timed Words keep both endpoints null. Preserve an unchanged original Turn's original evidence rather than gratuitously recomputing it. Add positive tests: model t1 contains w1 with start/end null and timingOrigin `.none` (actual contract case) plus timed w2; split before w2 and assign w1 to another speaker separately. The w1-only segment must remain time unknown, w2 time stays 400000–700000, original Word fields unchanged, repository accepts and restart preserves. Do not weaken existing optional-time validator.

2. Public `TranscriptEditor.applying` calls Dictionary(uniqueKeysWithValues:) before validating input document/model. An invalid externally supplied document with duplicate Word IDs can trap instead of throwing. Validate input/model before dictionary construction (or use a checked construction). Add an invalid duplicate-ID regression asserting a typed failure and unchanged input, not process crash. Normal loaded sessions remain the main path.

3. Review cancellation after an ambiguous write success. `cancelFailedSave()` currently resets memory to old committed without checking disk. A repository may persist active intended revision then throw (e.g. final verification error). Retry already handles this case, but cancel could display 'saved' old content while restart loads the canceled edit. Use a test repository wrapper that delegates commit to real FileSessionRepository then throws once. Ensure cancel does not claim saved/enable export inconsistent with disk: reconcile actual active state and, if cancel restores old content, persist that restoration as a new immutable revision; otherwise retain an explicit recoverable error. Preserve existing old-pointer failure cancellation and retry behavior. Document the selected semantics, no file deletion.

Check fresh editor open recovery notices are not silently lost: later UI may consume repository.recoveryNotices(), or expose the loaded recovery notice from session. Document actual route in result for T06.

4. `SaveGate.release()` drops release if its continuation has not yet been installed; the test observes isSaving before beforeSave suspension is guaranteed. Make the gate retain a released permit or expose an entered handshake, so the overlap regression cannot hang by scheduling race. Avoid busy-yield as the sole proof the save actually reached the gate.

5. The initial rename test constructs anotherRun but never stores/loads/edits it, so that assertion is only a value-copy assertion. Add a real separately persisted Run (same provider labels), edit/rename the first session/Run through session, reopen the second and compare original speaker display names and evidence. Test reversion from model timingOrigin `.none` (null Word times) rather than only `.model`, to prove it consumes model provenance.
