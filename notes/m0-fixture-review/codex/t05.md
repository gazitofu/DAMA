# T-05: Faithful JSON/TXT export

Read common contract, plan T05/AC08–09, T02–T04 results and actual Core sources/tests. Implement T05 only. Allowed: Packages/DamaCore/ except DomainContracts.swift, and notes/m0-fixture-review/codex/t05-result.md. Do not edit app/UI/project/scripts/SSOT/fixtures/plan. Main-owned task files are intentional. Create the result file early, update actual measurements and finish promptly after required verification.

Implement a Foundation exporter using existing codec, validator and time presentation helper. Export a explicitly selected automatic model or current saved revision. Reuse FileSessionRepository model loading and editor's committed state; never silently export a stale/different displayed version or permit export while editor saving/dirty/failed. Public API must clearly identify which document is exported. No edits to source doc, no new AI processing, no reading unrelated state/audio/credentials.

Measured T04 interfaces: actor `TranscriptEditingSession.open(repository:sessionId:revisionFactory:)`, `state() -> TranscriptEditingState` (committed/draft/isDirty/isSaving/failure/canUndo/canRedo/canExport), apply/undo/redo/retry/cancelFailedSave async. A canExport snapshot alone is not a lock across suspension: coordinate export preparation/writing with the editor so a new save cannot race a stale checked state. Use a cohesive scoped export operation/lease or equivalent, with clear state and no misleading '저장 중' label for export. Test attempted overlapping edit while an export operation is intentionally suspended and vice versa. Actual model is already privately loaded in session; preserve automatic/current selection rather than reloading an unrelated active Run. Later UI should pass an explicit displayed revision identity and reject stale selection if necessary.

JSON is the complete normalized schema with all explicit nullable fields and untouched provenance, word originals, model candidates, marker and issue states. Do not attach UI/internal paths or new schema keys. TXT uses blank-separated blocks `[HH:MM:SS.mmm–HH:MM:SS.mmm] 화자 이름`, content assembled from selected words' prefix + editedText-or-text in document Turn order; preserve repetitions/prefixes and independent marker blocks. Null speaker exactly `화자 미확정`, unknown time `시간 미확인`. MissingSpeech uses markerText verbatim, never an invented word. Preserve uncertainty via visible issue/overlap/unknown annotations; human acknowledgement never turns overlap/unknown into an accuracy guarantee. Scores are not a probability percentage. Use explicit metadata/header distinct from transcript content to identify synthetic provenance and selected version.

Write only to a caller/user-selected file URL. Encode and validate first, temporary sibling file and atomic replacement on success; errors must preserve an existing destination if replacement fails, and surface a sanitized actionable error without transcript/path values. Any overwrite is invoked only by the app after NSSavePanel's normal user selection/overwrite decision; exporter must not invent a default destination. Do not touch repository files or automatically send exports elsewhere. Reject repository-root/session paths if the API knows the root, or clearly require caller-level exclusion and implement that in subsequent UI task.

Main measured FileSessionRepository.rootURL is private, and `loadModel(sessionId:runId:)`/`loadWithRecovery(sessionId:revisionId:)` exist. Prefer a small repository method validating a selected export destination against its own resolved root, consumed by the export/session coordinator. Do not duplicate the Application Support namespace in UI or leave internal-file overwrite protection as an unimplemented promise. Test both direct and symlink aliases into storage are refused before any write.

Tests cover four combinations automatic/model vs current edited revision × JSON/TXT with independent expected content, fixture markers/unknown/confidence-map/null, edited current vs immutable automatic, reloading JSON, no collapsed A-marker-A boundaries, microsecond display pins, nil times and repeated words, selected version labeling and synthetic provenance, success to temp destination and injected/real write failure leaving prior destination intact. Search output for unintended local storage path/URL/credential metadata (use sentinel in tests, not actual keys). Do not redact user transcript text based on arbitrary words; test output structural isolation using synthetic metadata/sentinels.

Run bash scripts/check.sh. Respect known Xcode sandbox failure handling and prohibition on xcodebuild test/signing. Write actual exporter signatures, tests/commands/results, numeric mini-audit linkage to T02 and limitations to t05-result.md. No interactive UI yet.
