②문단을 보며 원구간 하나씩 편집

큰 입력칸을 수십 개 펼치던 방식을 없앱니다. 문단 안에서 원구간을 고르고 입력칸 하나로 수정합니다. 문단 전체 자유 편집은 별도 설계가 필요하므로 첫 묶음에는 포함하지 않습니다. 원문·시간·화자와 저장 구조는 보존합니다.

아래 시안을 조작한 뒤 채팅에서 확인해 주세요.

03
확정할 동작


읽기와 보조 정보
  • Scripts 상단은 제목, 녹음 날짜/길이/현재 엔진, 내보내기. Run ID·모델 세부·원본/교정·인원·참고 입력은 정보 영역으로 이동합니다.
  • 기본은 inspector 닫힘. 검수와 정보는 하나의 영역을 교대로 열며, 닫아도 원문과 경고 배지는 그대로입니다. 검수 건수는 이슈의 자동 해소/정답 판정이 아닙니다.
  • 행 클릭은 선택. 선택된 행에 수정/표시 이름/문단/검수 기록을 노출하고 키보드 포커스에서도 같은 조작에 접근합니다. 경고 배지·화자명은 hover 없이 보입니다.
  • Speeches의 녹음·변환·동의·재개·보존 동작은 유지합니다. Scripts의 재전사·삭제는 정보 영역의 명시적 명령으로 옮기고 기존 확인창/차단 조건을 유지합니다.
  • ‘다른 결과 보기’는 기존 단일 결과 전환입니다. 동시에 양쪽을 보는 비교나 같은 시간 자동 연결로 표시하지 않습니다. 저장 중/편집 중에는 기존 canLeave 차단을 유지합니다.


원구간 선택 편집
  1. 선택한 ScriptBlock의 원 Turn들을 순서대로 문단 안에 표시합니다. 각 원구간은 원 Turn ID와 연결하며, 첫 구간이 초기 선택입니다. 구두점·0길이·빈 대사도 선택할 수 있습니다.
  2. 선택한 원구간 하나를 입력칸에 표시합니다. 입력은 draft에 즉시 반영하고 문단 미리보기를 갱신합니다. 이전/다음 구간은 첫/마지막에서 비활성화하고 자동 순환하지 않습니다.
  3. 저장할 때 변경한 Turn에만 기존 editText를 적용하고 기존 recordReview/saveScript/expectedHash 경로를 사용합니다. 원 normalized·시간·화자 ID·marker·다른 Run은 불변입니다.
  4. 검수 기록은 기본 접힘. 원음 확인 기본 false, 오류/표본 기본 unclassified, 메모 빈값, 능동 시간 nil을 유지합니다. ‘오류 없음’은 원음 확인 전 저장 불가. 표시 이름 범위는 현행 전체 기본과 대상 수 확인을 유지합니다.
  5. 저장 중 중복 저장·닫기·파일 전환을 차단합니다. 성공한 뒤 닫고 같은 대상의 표시를 갱신합니다. 실패하면 입력과 선택 구간을 유지하고 오류를 표시합니다. 취소/Escape는 draft만 버리고 파일을 쓰지 않습니다.
문단의 통합 문자열을 한 Turn에 몰아넣거나 임의로 쪼개 저장하지 않습니다. 자유 문단 편집 선택 시 저장 계약/분절/이력/Markdown을 다시 설계한 뒤 해당 축을 확인받습니다.3


재생과 사건 이동
  • 고정 막대는 선택된 행/사건의 시간 범위, 실제 positionUs, 재생/정지, 현재 문단 이동을 표시합니다. 선택 변경 시 기존 재생을 정지하고 대상을 바꿉니다. 자동 재생은 하지 않습니다.
  • 일반 행은 기존 범위 재생, 사건은 기존 ±2초 context, 0길이는 기존 앞뒤2초와 안내를 유지합니다. 원 시간은 바꾸지 않습니다. seek·속도·반복·일시정지 재개는 첫 묶음에 포함하지 않습니다.
  • 검수 사건 선택은 기존 근거와 연결된 첫 문단으로 이동합니다. 동일 사건이 여러 문단에 걸치면 inspector에 연결 구간 목록을 보여 각각 이동할 수 있게 합니다. 근거 연결이 없는 사건은 ‘본문 연결을 확인할 수 없습니다’로 남기고 가까운 화자로 채우지 않습니다.
  • 사건 순서는 기존 reviewEvents 배열을 유지합니다. 다음/이전은 끝에서 멈추고 마지막/첫 상태를 표시합니다. 시간 nil이면 이동 가능한 텍스트 근거는 보여도 재생은 비활성입니다.
  • 재생 tick은 하단 소형 뷰에서만 관찰합니다. 전체 reading snapshot 재계산은 추가하지 않습니다. 녹음 시작 시 재생 정지, 녹음 중 재생 비활성, 종료 시 대상 범위 유효성 재확인.

수정 경계와 검산
재사용
  • normalized 모델·P2TimeEvidence·reading-v6 snapshot·ScriptBlock·reviewEvents·화자/시간/marker 불변식.
  • LibraryWorkspace 저장/충돌/재개/전송 동의/내보내기, turnTexts/turnNames/paragraphBreaks/reviewRecords.
  • SegmentPlayback play/stop/listeningRange/positionUs, 녹음 우선 차단과 기존 파일별 실패 격리.
변경
  • UI/LibraryShell.swift 배치·행 선택·정보/검수 영역·편집 시트 구성. App/DamaApp.swift 창/명시적 키보드 조작.
  • 표시 문구2종과 새 navigation 상태. model/provenance/원문 export 내용은 이 화면 변경으로 바꾸지 않음.
신규
  • 선택 행/사건/inspector UI 상태, 근거로 연결된 block 인덱스, 선택 원구간 draft 제어.
  • 재생 상태를 관찰하는 고정 막대. polling tick이 본문 전체 계산으로 전파되지 않도록 분리.
검산과 종료
  1. 동일 저장3경로에서 normalized/문단/Markdown 지문 및 입력14파일 불변. 사람 편집은 합성 사본으로 저장→재열기→Markdown을 대조.
  2. 원구간21개 재현에서 입력칸1개, 구간 전환 시 draft 유지, 취소0쓰기, 저장 실패 draft 유지. 서로 다른 B/미확정/누락 경계로의 자동 병합0.
  3. 검수 사건의 연결 문단/다음·이전/끝 상태, 시간 nil·0길이·녹음 중 차단 검증. 재생 실시간 표시는 네이티브 실제 실행에서 확인.
  4. 900×600과1180×760, 라이트/다크, Tab·Return·Escape·Cmd-Return·내보내기와 VoiceOver 실물. 배지 의미를 색 없이 읽을 수 있어야 함.
  5. 필수 여정과 영향 회귀를 한 번에 확인한 뒤 종료. 정확도·모델 학습·속도 개선율·음성 정답은 안 잼.
비범위: 자유 문단 편집, 새 ASR/화자 귀속 정책, 자동 전송, 학습, 동기화 비교, 검색, seek/속도/반복, 배포.
