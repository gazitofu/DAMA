본문 중심 배치

  • 검수 기록, 원음 확인 체크, 오류/표본 분류, 능동 시간, 검수 메모·건수·기록 이력과 별도 검수 목록을 UI에서 제거합니다. 선택 행에는 원음 듣기와 수정만 둡니다. 내부 기존 기록은 보존합니다.

제목은 그 자리에서 입력하고 자동 저장

  1. 상단의 스크립트 제목을 클릭하거나 Tab으로 이동하면 제목 자리에서 바로 입력합니다. 제목용 수정/저장 버튼, 모달, 새 탭은 없습니다. 한 줄 입력이며 현재 글꼴·위치·너비를 유지합니다.
  2. 입력은 즉시 제목에 표시합니다. 한글 조합이 끝나고 마지막 변경 후500ms 동안 추가 입력이 없으면 자동 저장합니다. 포커스를 벗어나거나 Enter를 누르면 대기한 저장을 즉시 마칩니다. Enter는 줄바꿈을 만들지 않습니다.500ms는 품질 측정값이 아닌 초기 UI 구현값입니다.
  3. 저장 성공 후 Scripts 목록과 현재 결과의 제목을 함께 갱신합니다. 같은 원음의 다른 Run에는 이름을 전파하지 않고, 원 파일 경로나 녹음 날짜·정렬 순서도 바꾸지 않습니다. AI 과거 버전은 당시 제목을 읽기 전용으로 표시합니다.
  4. 제목이 비었거나 공백뿐이면 저장하지 않고 ‘제목을 입력해 주세요.’를 표시합니다. 입력 draft와 마지막 저장 제목을 따로 유지합니다. 실패 시 ‘제목을 저장하지 못했습니다. 입력한 내용은 유지됩니다.’를 같은 제목 주변에 표시합니다. 다시 입력하거나 제목에 들어왔다 나오면 재시도하며 별도 저장 버튼은 없습니다.
  5. Escape는 아직 저장되지 않은 제목 입력을 마지막 저장 제목으로 되돌립니다. 이미 성공한 자동 저장을 소급 취소하지 않습니다. 변경이 없으면 새 revision을 만들지 않습니다. 조합 중 Enter/Escape는 입력기가 먼저 처리합니다.
  6. 자동 저장 대기/실패 중 파일·결과 전환, 본문/화자 편집, AI 실행과 내보내기는 저장 상태가 정리될 때까지 차단합니다. 본문 편집 draft가 열렸거나 과거 결과/빈 상태에서는 제목을 읽기 전용으로 둡니다. 저장 호출은 순차 실행하고 최신 제목만 후속 저장하며 외부 hash 충돌을 덮어쓰지 않습니다.
  7. 제목 변경은 기존 LibraryScript.title/renameTitle·revisionID·saveScript의 계약을 재사용합니다. AI 완료/본문 저장과 겹치면 최신 파일을 읽어 해당 필드만 병합하고 외부 변경 충돌은 실패로 남깁니다. 원문·시간·화자·기존 보정/수정본은 유지합니다.

화자 이름 클릭 → 이름 변경 모달

  1. 현재 결과의 화자 이름과 ‘화자 미배정’은 버튼입니다. 클릭하면 ‘화자 이름 변경’ 모달에서 표시 이름을 입력합니다. 별도 ‘표시 이름’ 행 버튼은 없습니다.
  2. ‘이 부분만 / 이 부분부터 / 전체’의 기존 범위 규칙과 대상 원구간 수를 표시합니다. 알려진 화자는 현행 전체 기본을 유지합니다. 미배정은 같은 인물임을 알 수 없으므로 이 부분만 허용합니다.
  3. 이름 변경은 turnNames 사람 수정입니다. 원 화자 ID와 공급자 후보를 덮거나 다른 Run으로 전파하지 않습니다. 모달에 ‘원래 화자 ID는 보존됩니다.’를 표시합니다. 빈 입력은 저장 불가, 취소/Escape는 쓰기 없이 닫힙니다.

묶음의 ‘이 부분만’은 원 Turn 전부, ‘이 부분부터’는 첫 Turn부터 같은 원 화자, ‘전체’는 이 Script의 같은 원 화자입니다. 미배정 범위 제한은 잘못된 일괄 변경을 막기 위한 r2 UI 정책입니다.ssot/contracts/library-script.md 연속 발화 표시; LibraryScript.rename/affectedTurns 및 LibraryShell의 현행 이름 변경 범위. null은 다른 인물과 동일한 ID로 간주하지 않음.

수정 → 같은 본문에서 입력 → 같은 버튼으로 저장

  1. 선택한 문단의 ‘수정’을 누르면 지금 읽던 본문 자체가 편집 가능해집니다. 글꼴·행간·폭·본문 시작 위치를 유지합니다. 원구간 선택 줄, 별도 입력칸, 미리보기, 새 창은 추가하지 않습니다. 커서를 놓고 문단 안의 글을 바로 고칩니다.
  2. 편집을 시작해도 내용이 같으면 같은 버튼은 ‘수정’으로 남고 중복 진입만 막습니다. 실제 문자열이 달라지는 순간 그 버튼이 같은 자리에서 ‘저장’으로 바뀝니다. 직접 되돌리기/실행 취소로 시작 문자열과 같아지면 다시 ‘수정’이 됩니다. 저장하지 않은 공백·줄바꿈 변경도 변경으로 셉니다.
  3. 같은 조작 줄에 ‘취소’를 표시합니다. 취소/Escape는 draft만 버리고 읽기 상태로 돌아갑니다. 변경 없이 빠져나와도 쓰지 않습니다. 저장 성공 후 같은 본문이 읽기 상태로 돌아가고 버튼은 ‘수정’으로 복귀합니다.
  4. 한 번에 한 문단을 편집합니다. 문단 안의 삽입·삭제·줄바꿈·붙여넣기·한글 조합 입력을 지원하며 공급자의 원구간 경계에서 커서를 막지 않습니다. Enter는 문단 안 줄바꿈입니다. 다른 화자의 문단이나 누락 marker를 합치거나 편집 대상으로 삼지 않습니다. 빈 대사로 저장해도 원 구간·시간은 남기고 해당 행을 삭제하지 않습니다.
  5. 편집 중에는 다른 행 편집·이름 변경·파일/결과 전환·AI 실행·내보내기를 차단합니다. 본문을 밀어내는 새 편집 배너는 없으며 기존 도구줄에 ‘본문 편집 중’ 또는 ‘저장하지 않은 변경’을 표시합니다. 원음 재생·현재 문단 이동은 가능합니다.
  6. 저장 중 버튼을 ‘저장 중…’으로 바꾸고 편집·중복 저장·이탈을 막습니다. 저장 실패는 같은 본문/draft/선택을 유지하며 ‘저장’으로 재시도할 수 있게 합니다. Cmd-Return은 변경이 있고 한글 조합이 끝났을 때만 저장합니다. IME 조합 중 Return/Escape는 입력기가 먼저 처리합니다.

D-02 · 문단 수정본과 원문 연결

본문을 자연스럽게 편집하는 UI는 사용자 후속 지시로 확정합니다. 현재 저장 계약은 원 Turn별 turnTexts이므로 자유롭게 고친 문단을 원 Turn들에 임의로 나누지 않는 저장 확장으로 확정합니다.

  • 문단 수정본을 별도 사람 수정 layer로 저장합니다. 같은 Run 안의 순서 있는 원 Turn ID 묶음, 저장 기준 revision/본문 지문, 수정 문자열을 연결합니다. 원 normalized·word/Turn·화자 ID·시간·marker·기존 turnTexts와 reviewRecords는 보존합니다. 새 일반 수정은 검수 완료/정답/학습 허용 기록을 만들지 않습니다.
  • 수정본은 원 문단의 시간 범위와 화자를 유지하며 ‘사용자 수정’으로 표시합니다. 각 글자의 발화 시간을 새로 추정하지 않습니다. 원구간이 여러 개인 문단도 수정 문자열을 첫 Turn에 몰거나 글자 수로 재분배하지 않습니다.
  • 저장 때 보이는 문단의 원 Turn 묶음과 기준 revision/파일 hash를 재확인합니다. 외부 변경이나 겹치는 문단 수정 충돌이면 draft를 유지하고 실패합니다. 문단의 원 경계를 고정해 이후 읽기 재구성이 다른 화자/marker까지 포함하지 못하게 합니다.
  • 재열기·Markdown·AI 버전 snapshot은 같은 문단 수정본을 소비합니다. 저장된 연결이 없거나 충돌하면 수정본을 원문으로 조용히 치환하지 않고 ‘수정본 연결을 확인할 수 없습니다.’로 표시하며 해당 결과의 저장/내보내기를 차단합니다. 구 파일에 이 layer가 없으면 기존 표시를 그대로 사용합니다.
  • 문단 수정본은 AI보다 우선합니다. 사람이 고친 문단은 이후 AI 실행의 읽기 전용 참고 문맥으로 보내고, 그 문단의 원 Turn들은 새 교정 적용 대상에서 제외합니다. 사용자가 새로 고친 문단과 이전 AI 버전을 섞어 덮지 않습니다. AI 완료 시 최신 사람 수정 layer를 다시 병합합니다.
  • 화자 이름 모달은 현재 문단에 연결된 원 Turn 전부에 같은 이름을 적용합니다. 문단 대사 수정본을 재분절하거나 다른 Run으로 옮기지 않습니다. 첫 성공 이전/완료 snapshot에는 당시 문단 수정본을 함께 보존합니다.
