Nemotron 3 화자 분리로 운영 경로 교체

pyannote Precision-2를 빼면서 운영 경로가 Soniox 단독으로 떨어졌고, 인원이 줄어드는 문제(E2)가 그대로 남는다. 이 유닛은 이 Mac에서 도는 Nemotron 3 화자 분리를 P2 자리에 넣어 Soniox 전사 + Nemotron 3 화자 분리를 새 운영 기본값으로 만든다.

확률에서 구간 만들기 (nemotron-intervals-v2)

  
단위는 내부 Int64 µs, 반열린 구간 [start, end)다(INV-02). 프레임 i는 [i × 10,000, (i + 1) × 10,000) µs이고 끝은 녹음 길이에서 자른다. 시작이 녹음 길이 이상인 프레임은 버린다.

  
    
    
  1. 활성: 확률이 0.5보다 클 때만 활성이다. 정확히 0.5는 비활성이다.FluidAudio segments 단일 임계 > 0.5 · NeMo 기본 onset/offset 0.5 · 한국어 실측 전 초기 설계값 · research-C2 1.2–1.3절.
    2. 
    
  2. 일반 구간 diarization: 채널별로 활성 프레임이 이어진 최대 구간 하나가 구간 하나다. 최소 길이, 패딩, 같은 채널 틈 메우기는 하지 않는다. 10 ms 한 프레임도 구간이 된다. 서로 다른 채널의 구간은 겹칠 수 있다(INV-07).
    3. 
    
  3. 단독 구간 exclusiveDiarization: 프레임마다 활성 채널 중 확률이 가장 높은 채널 하나를 고르고, 같은 채널로 이어진 최대 구간을 구간 하나로 한다. 활성 채널이 없거나 최고 확률이 둘 이상으로 같으면 그 프레임은 단독 구간에 넣지 않는다. 공급자 출력이 아니라 앱 파생값이며, 일반 구간(겹침 포함)을 대체하지 않는다.r2 근거: 설치 앱 Run E33ADFD9(BED2C097) 미배정 1,387 중 1,275(92%)가 두 채널 이상 활성 프레임에만 걸친 토큰 · 저장된 P2 13개 원응답은 겹침 프레임 236,162개를 단독 구간이 100% 한 화자로 덮음 · .build/check-logs/nemotron-diarization/unassigned-diagnosis.txt · 사용자 2026-10-30 «v2로 변경». r1(nemotron-intervals-v1)은 활성 채널이 정확히 하나인 프레임만 썼고, 그 버전으로 만든 Run은 그대로 재현한다.
    4. 
    
  4. 화자: 일반 구간이 하나라도 있는 채널만 화자가 된다. 채널 번호 순(첫 발화 순서)으로 «화자 1, 2, …»를 붙인다. 화자 ID는 이 Run 안에서만 유효하며 다른 Run의 화자와 자동으로 잇지 않는다(INV-09).
    5. 
    
  5. confidence: 모든 구간에서 null이다. 채널 확률 평균은 앱이 계산한 값이라 공급자 점수 자리에 넣지 않는다(INV-08). 따라서 low_confidence 이슈는 생기지 않는다.
    6. 
  

  
이 규칙의 쪼개짐은 P2와 같은 규모다. 같은 12개 녹음(10.97시간)에서 일반 구간은 시간당 Nemotron 1,864개, P2 1,489개였고, 200 ms 미만 구간은 각각 95개, 236개였다.2026-10-30 이 스펙 작성 중 읽기 전용 측정 · 모집단 = P2 원응답과 1a 확률이 모두 있는 12개 녹음 · Nemotron은 위 1·2 규칙, P2는 원응답 diarization 개수 · 스크립트 notes/nemotron-diarization/fragmentation-check.py (인자 = 내부 Sessions 폴더, .build/diagnostics/nemotron). 텍스트 없는 일반 구간마다 누락 의심 marker가 생기는 기존 규칙은 그대로 둔다.


  
단어 배정

  
    
    
  • 위에서 만든 일반·단독 구간을 P2 구간 자리에 넣고 B2 규칙(soniox-p2-word-v4)의 배정·문장부호·어절 공유·장벽·이슈 생성을 그대로 적용한다. 새 문턱·시간·문자열을 만들지 않는다.
    • 
    
  • 결합 버전 이름은 soniox-nemotron-word-v3이다. 의미 = «nemotron-intervals-v2 구간 + v4 배정 규칙 + 아래 어절 안 화자 맞춤». 새 Run은 v3, 저장된 버전이 v1·v2인 Run은 재개·재현 때 저장된 버전을 쓴다. 지원하지 않는 버전은 실패하며 자동 치환하지 않는다. 이미 v2로 만든 녹음을 v3로 보려면 «다시 전사»로 새 Run을 만든다(Soniox·Nemotron 결과 재사용).
    • 
    
  • 겹침 프레임의 단독 화자는 확률 차이가 작아도 고른다(BED2C097 겹침 토큰의 63%가 평균 확률 차 0.05 미만). 실제 동시발화의 귀속 오류(E1) 위험이 있으므로 해당 단어의 overlapping_speech 이슈는 유지한다.
    • 
    
  • Soniox 토큰의 문자열·공백·순서·원시간·ASR confidence·언어와 원 Soniox 화자 후보(asrSpeakerLabel)는 불변이다. 두 공급자의 화자 전환이 엇갈리면 기존처럼 provider_disagreement를 남긴다.
    • 
  


  
어절 안 화자 맞춤 (r3)

  
겹침 구간에서 두 채널 확률이 거의 같으면 프레임마다 최고 채널이 바뀌어, 한 사람이 말한 어절의 조각이 다른 화자로 갈린다(BED2C097 v2에서 갈린 어절 218개, v1 89개).v1·v2 결합 문서 비교(설치 앱 Run E33ADFD9·108E3A3C) · v2의 새 «Soniox와 화자 다름» 326건 중 300건은 v1에서 한쪽이 미배정이라 검사되지 않던 단어 쌍, 211건(전체 525 중)은 한 어절 안 · 새 이슈 단어의 평균 확률 차 중앙값 0.009–0.039. 한 어절을 두 사람이 나눠 말할 수 없으므로 이런 어절만 이웃 어절의 화자로 맞춘다.

  
    
    
  1. 어절: 원문 공백·줄바꿈으로 나눈 토큰 묶음이다. B 규칙(soniox-p2-word-v3)의 어절 조각과 같은 분할이다.
    2. 
    
  2. 대상: lexical 토큰이 2개 이상이고, 배정된 화자가 서로 다른 2명 이상인 어절. 한 화자와 미배정만 섞인 어절, 어절 하나 전체가 앞뒤와 다른 화자인 어절(A [B] A)은 대상이 아니다(INV-06).최근 결합본 12개(P2 10 · Nemotron 2) 어절 69,814개: 어절 하나 섬 295개 중 204개는 Soniox도 다른 화자로 본 문장 끝 응답(«맞아요.», «네.» 등)이고 BED2C097에서 확률 차 중앙값 0.985 · 붙이면 E2.
    3. 
    
  3. 이웃: lexical 토큰이 있는 바로 앞 어절과 바로 뒤 어절. 앞 어절은 앞 어절 안에 문장 끝 부호나 줄바꿈이 없을 때만, 뒤 어절은 대상 어절 안에 그런 부호가 없을 때만 본다. D-06 ⓑ면 앞 어절만 본다.
    4. 
    
  4. 이웃 자격: 이웃 어절의 lexical 토큰이 모두 같은 한 화자로 배정되어 있고(미배정 없음), 대상 어절과 이웃 어절의 lexical 토큰 Soniox 화자 후보(asrSpeakerLabel)가 모두 같은 nonnil 값이다. Soniox 후보는 같은 원문 구절 조건으로만 쓰고 Nemotron 화자와 매핑하지 않는다(B2와 같음).
    5. 
    
  5. 맞춤: 자격 있는 이웃의 화자가 정확히 1명이면 대상 어절의 배정된 lexical 토큰을 그 화자로 바꾼다. 0명이거나 2명 이상이면 그대로 둔다. 대상 어절 안의 미배정 조각은 D-07을 따른다.
    6. 
    
  6. 판정 시점: 모든 대상 어절을 이 단계 직전의 배정 한 장으로 판정한다. 앞에서 바꾼 결과를 다음 어절의 이웃 판정에 쓰지 않는다.
    7. 
    
  7. 순서와 기록: B2의 꼬리 공유 다음, 닫는 부호 부착 앞에서 돈다(v5와 같은 자리). 바꾼 토큰의 sourceIntervalIds는 자기 것에 이웃 어절 lexical 토큰들의 것을 합치고 alignmentScore는 null이다. overlap·boundary 이슈는 토큰별 직접 계산값을 유지한다. provider_disagreement·unrepresented_speaker·ambiguous_speaker는 바뀐 배정으로 기존 규칙대로 다시 생긴다.
    8. 
  

  
    
    
  • 새 문턱·시간값을 만들지 않는다. 문장 끝 부호는 . ? ! 。 ？ ！ …이다(청취 표본에 쓴 경계).
    • 
    
  • 겹침의 소수 화자 쪽 단어가 줄어 unrepresented_speaker가 늘어난다(19개 합계 4,200 → 5,174, 앞 이웃만이면 4,975). 그 구간에 다른 사람이 말했다는 검수 표시이므로 줄이지 않는다.
    • 
    
  • P2 결합 경로(soniox-p2-word-v4)와 비교 전용 v5는 바꾸지 않는다.
