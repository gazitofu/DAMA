02-1 Nemotron 입력 음량 (D-05 · nemotron-input-level-v1)

  
    
    
  1. 자리: 분석 WAV를 Float32로 읽은 뒤 processComplete에 넣기 직전, 메모리에서만 한다. 분석 WAV 파일·녹음 원본·Soniox 업로드·재생은 바뀌지 않는다.읽기 Packages/DamaNemotron/Sources/DamaNemotron/FluidNemotron.swift:28 · 호출 :20.
    2. 
    
  2. 측정: 표본을 1,600개(0.1초)씩 겹치지 않게 나눠 창마다 RMS dBFS = 20·log10(√(평균 x²) + 1e−9)를 구하고, 모든 창의 90번째 백분위수 P90을 쓴다. 남는 끝 표본(1,600개 미만)은 측정에서 뺀다.
    3. 
    
  3. 이득: g(dB) = min(24, max(0, −20 − P90)). 선형 배율 = 10^(g/20).
    4. 
    
  4. g = 0이면 아무 처리도 하지 않는다(입력 표본이 지금과 바이트 동일).
    5. 
    
  5. g > 0이면 v = x·배율에 소프트 리미터를 건다: |v| ≤ 0.7이면 그대로, 넘으면 부호 유지 0.7 + 0.3·tanh((|v| − 0.7)/0.3).
    6. 
    
  6. 기록: nemotron-meta.json에 inputLevel = {version «nemotron-input-level-v1», gainDb(소수 2자리), p90Dbfs(소수 2자리)}를 더한다. 기존 meta에는 키가 없다.
    7. 
    
  7. 재사용: 지금 재사용 조건(session · 분석 WAV SHA256 · 모델 목록 SHA256 · FluidAudio 버전 · 프리셋 · 채널 수 · 확률 파일 크기)에 inputLevel.version 일치를 더한다. 키가 없는 기존 결과는 새 Run에서 재사용하지 않는다. 기존 Run의 열람·재현은 저장 확률 그대로다.현행 조건 ManagedProcessor.swift:215–229.
    8. 
  

  
단위: 입력 = Float32 선형 진폭(−1…1) · 측정 = dBFS · 이득 = dB → 선형 배율 · 출력 = Float32 선형 진폭. 숫자 −20 · 24 · 0.7 · 90번째 백분위수는 표 3 실험 3건에서 정한 신규 후보값이다.
