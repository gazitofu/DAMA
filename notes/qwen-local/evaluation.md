# Qwen 로컬 비교 구현 실측 — 2026-09-11

**비교 엔진 구현 완료, 기본 엔진 승격 보류.** M5 Pro/48GB에서 21분 53.280초 녹음 전체를 로컬 ASR + 정렬로 처리하고 기존 Precision-2 결과와 결합했다. 앱 0.3.0 (9)에 비교 엔진을 추가했다. 품질 정답·E1/E2·능동 수정 시간은 아직 측정하지 않았다.

## 앱 실행 결과

- 한국어, float16 ASR1.7B + aligner0.6B, 기존 맥락·참석자 입력, 예상 화자 3명. 참고 폴더 발췌 OFF, AI 교정 OFF.
- 실제 앱 프로세스 추론·정렬 100.30초. 초기 CLI 파일럿 성공 실행은 92.13초였다. 동일 설정이어도 출력이 비트 단위로 동일하지 않았다. 속도는 모델 다운로드를 제외하며 전체 UI 왕복 시간과 다르다.
- 완료 leaf 청크 19개. 반복 종료 부모 청크 3개를 짧게 다시 처리해 복구했다. 실패 원출력도 private checkpoint에 보존했다. 완료 결과는 모든 청크 EOS, 전체 frame 연속 범위 검사를 통과했다.
- 앱 실행 최대 RSS 4,450,811,904 bytes, MLX peak 8,158,413,560 bytes. 서로 다른 메모리 측정값이므로 더해서 전체 사용량으로 해석하지 않는다.
- 실제 재사용 Precision-2 raw bytes 동일 확인. 새 Run에 클라우드 제출 request.json 없음, 기존 source Run ID 기록. 추가 ASR/화자분리 API 호출 없이 수행했다.
- 새 Script 1개 생성, 기존 Script 5개는 실행 전후 SHA256 동일. 최종 앱 재시작 후 새 결과 다시 열기 확인.
- 한국어 정렬 단위 사이에 UI가 공백을 추가하던 연결 오류 발견·수정. 최종 화면에서 원문 공백이 보존됨을 확인했다. JSON 원문은 이 표시 변경으로 수정하지 않았다.

## 구조 비교 (정확도 점수 아님)

동일 녹음, 기존 Soniox 기본 문맥+3명 힌트 결과와 비교했다. Soniox는 자체 diarization, Qwen은 기존 Precision-2를 쓰므로 화자분리 조건은 다르다. Soniox+동일 P2 결합 기준선은 이번에 새로 만들지 않았다.

| 항목 | Soniox 기본 문맥·인원 힌트 | Qwen 로컬 + 기존 P2 |
|---|---:|---:|
| 예상 / 감지 화자 | 3 / 2 | 3 / 3 |
| ASR 원문 공백 제외 문자 수 | 6,199 | 5,538 |
| 발화 문단 | 434 | 1,013 |
| 시간 있는 문단 중 1초 미만 | 146 | 415 |
| 시간 미확정 문단 | 0 | 336 |
| 전사 누락 의심 마커 | 0 | 81 |

문자 수가 적다는 사실만으로 누락률을 계산할 수 없다. 짧은 문단 수에는 정렬·화자 보류 정책의 영향도 포함된다. Soniox의 경고 0개가 오류 0개를 의미하지 않으며, 공급자 토큰과 Qwen 한국어 정렬 항목은 같은 단위가 아니다.

Qwen 2,587개 정렬 항목 중 336개(12.99%)의 시간이 사용할 수 없어 null로 보존됐다. 최종 화자 미확정은 566항목(21.88%)이며, 정렬 미확정과 겹말·경계 보류를 포함한다. 발화 문단 1,013개 중 시간이 있는 677개의 중앙값은 0.64초, 최장은 20초다. 현재 정렬·보류 결과는 읽기 문단 분절을 충분히 줄이지 못한다.

**이번 버전의 다음 품질 과제는 정렬이다.** 0길이 정렬을 임의로 늘리거나 앞뒤 화자에 합쳐 경고를 숨기지 않았다. 1) 원음 확인 가능한 짧은 표본에서 한국어 정렬 0길이·경계 오차를 먼저 평가하고, 2) 동일 Precision-2를 고정한 Soniox 대 Qwen 텍스트/정렬 비교, 3) 필요한 경우 불확실 구간 재정렬을 별도 버전으로 보존하는 순서가 적절하다. 97분 확장과 기본 엔진 교체는 후속이다.

## 검증 근거

- Swift 영향 검사 고유 82개 PASS (Qwen/Core·managed·Soniox·저장·문단·문맥 교정 관련). 계약 검사 30개 PASS와 DomainContracts 양쪽 동일 확인. Python worker 검사 4개 PASS. `xcodebuild` 최종 BUILD SUCCEEDED.

- 실제 앱 중단/재개 및 추론 중 앱 종료 시 child 종료는 아직 실기기 검증하지 않았다. 합성 재개 검사와 구현/빌드 검증만 완료했다. 이를 정상 완료 실행 실측과 구분한다.
