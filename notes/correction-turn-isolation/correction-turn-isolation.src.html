AI 교정 Turn 단위 검증 격리

AI 응답에서 검증을 통과하지 못한 Turn 하나가 청크 전체를 버리게 하던 규칙을 바꾼다. 그 Turn만 원문을 유지하고 같은 청크의 다른 Turn은 지금 규칙대로 검증·반영하며, 버린 Turn과 걸린 규칙을 본문 없이 남긴다.입력 = 사용자 «A로 가고 작은 유닛으로 /spec부터 하자» (2026-11-07) · notes/usage-review/correction-measure.md 진단 · notes/usage-review/decisions.md 부칙 2026-11-07 ①.

ⓐ는 교정 기록에 선택 필드 rejectedTurns(Turn ID와 규칙 코드)를 더한다. 기존 파일은 그대로 열리고 다시 저장해도 바이트가 같다. ⓑ는 새 필드 없이 기존 편집 기록에 «원문 유지»로 넣는다. 이 경우 구간 정보의 «AI 후보:»와 Markdown의 «교정안:»에 원문이 그대로 찍히고, 기존의 «불확실해 원문 유지» 기록과 모양이 같아 구분되지 않는다. 화면 절 문구는 ⓐ 기준이다.구간 정보 «AI 교정/AI 후보» 줄 UI/ScriptReadingView.swift:256. ①정책 (§02)

무엇이 청크 실패로 남고 무엇이 Turn 실패가 되는지, 청크 안 Turn이 전부 실패해도 청크를 성공으로 세는지, 버린 Turn을 다시 보내지 않는지를 본다.

02-2 Turn 실패의 처리

  
    
    
  1. 그 Turn은 편집 기록을 만들지 않는다. 본문은 지금 표시 우선순위(사람 수정 → 적용된 AI 교정 → 원문) 그대로이므로 원문(사람 수정이 있으면 사람 수정)이 보인다.
    2. 
    
  2. rejectedTurns에 항목 1개(turnID, rule)를 남긴다(D-02 ⓐ).
    3. 
    
  3. 같은 청크의 다른 Turn은 지금 규칙대로 검증하고, 수정별 판정(context-correction-6 ①–④)과 의미 보호를 그대로 적용한다.
    4. 
    
  4. 이름 매핑(참석자 목록 + 자기소개 인용)은 지금처럼 청크의 원문 Turn으로 따로 검증한다. Turn 실패와 관계없다.
    5. 
    
  5. 청크는 성공으로 센다. 청크 안 Turn이 전부 실패해도 성공이고, 완료 안내 띠에 버린 수가 보인다(03-2).
    6. 
    
  6. 모든 청크가 성공해야 한 번에 적용하는 규칙, 중단·오류 때 원문/이전 성공본 유지, 자동 재호출 없음은 지금과 같다.
    7. 
    
  7. 시도 기록의 끝난 청크 결과에 그 청크의 버린 Turn도 함께 둔다. 이어서 교정은 끝난 청크를 다시 보내지 않으므로 버린 Turn도 다시 보내지 않는다.
    8.

02-3 저장 (D-02 ⓐ 기준)

  
    
    
  • ScriptCorrection.rejectedTurns: 선택 배열. 항목 = turnID(문자열) · rule(quote · overlap · text · limit · reason · other). 비어 있으면 nil로 두어 키를 쓰지 않는다. 그래서 기존 파일은 그대로 열리고 다시 저장해도 바이트가 같다.
    • 
    
  • 저장 검증(validate)에 더한다: turnID는 발화 Turn ID 안, 중복 없음, edits의 turnID와 겹치지 않음, rule은 6개 중 하나. 어기면 지금처럼 손상(invalidScript)이다.
    • 
    
  • 시도 기록 CorrectionChunkResult.rejected: 같은 항목의 선택 배열. 형식 버전은 올리지 않는다(선택 필드가 없는 기존 기록도 해독된다).
    • 
    
  • 상태가 failed면 edits처럼 비운다.
    • 
    
  • «저장된 AI 교정 반영»은 rejectedTurns를 그대로 옮긴다. 버린 Turn은 다시 판정하지 않는다.재반영이 새 결과로 옮기는 값 = 편집·이름·근거·청크 수 CorrectionReapplication.swift:25–28.
    • 
    
  • 교정 뒤 사람이 그 Turn을 고치거나 지워도 rejectedTurns는 교정 시점 기록으로 그대로 둔다. 본문 표시는 사람 수정을 따른다.
    • 
  

  
D-02 ⓑ면: 버린 Turn을 CorrectionEdit(text = 원문, applied = false, changes·unresolved·appliedText = nil, 이유 = 문구 2)로 넣는다. 새 필드와 저장 검증 추가는 없고, 규칙 코드는 이유 문자열 끝 괄호로만 남는다.
