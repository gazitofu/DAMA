# 01. 제품 요구사항과 화면 명세

문서 버전: 1.0 · 작성/외부 사양 확인: 2026-09-09 · 프로젝트 가칭: Dama

## 1. 제품의 목적

이 앱은 한국어 대화 녹음을 **누가, 언제, 무슨 말을 했는지 확인 가능한 원문 스크립트**로 만든다. 사용자 경험의 최우선 순위는 원본 녹음 보존, 화자 전환 보존, 불확실성 표시, 수정 용이성이다. 회의록 요약은 이 앱의 역할이 아니다. 사용자는 결과 JSON/TXT를 다른 AI에 전달한다.

해결하려는 원래 문제는 두 가지다. E1은 A가 한 말을 B에게 귀속하는 오류다. E2는 A, B, C가 이어서 한 말을 한 사람의 문장으로 합치는 오류다. 문장의 자연스러움 때문에 E1/E2를 숨기면 안 된다.

이하 MUST는 필수 요구사항, SHOULD는 기본 권고, MAY는 후속 선택 기능이다. 별도 출처가 없는 UI 수치, 임계값, 구현 정책은 **제안한 설계값**이며 실측 성능이나 외부 서비스의 보장치가 아니다.

### 1차에서 제외할 것

요약, 액션 아이템, 회의 챗봇, 실시간 자막, 자동 참석자 실명 추정, 음성 지문 등록, 음원 분리, iPhone 원격 녹음 제어, 팀 계정, 자동 iCloud 동기화, 녹음 일시정지/재개, 시스템 오디오 캡처는 제외한다. 이 범위가 필요해져도 녹음 신뢰성과 E1/E2 수정 기능을 먼저 완성한다.

## 4. 최초 실행

온보딩은 '녹음'과 '클라우드 처리'를 따로 설정한다.

1. 녹음이 필요한 이유와 원본 저장 위치를 표시하고 마이크 권한을 요청한다.
2. 사용자가 API 키를 입력하면 Keychain에 저장한다. 키 설정을 건너뛰어도 녹음은 허용한다.
3. 클라우드 전송 정책을 선택한다. 기본은 `askEachSession`, 선택지는 `askEachSession / autoAfterStop / neverUpload`이다.
4. `autoAfterStop`을 선택할 때 음성 파일이 외부 서비스로 전송됨과 과금 가능성을 명시한다. 매 녹음에서 '이번 녹음은 로컬 저장만'으로 덮어쓸 수 있다.
5. 참석자 고지/회사 내부 보안 정책을 확인하도록 안내한다. 앱이 법적 허용 여부를 판단한다고 쓰지 않는다.

마이크 접근에는 사용 목적 설명과 권한 요청 경로가 필요하다. [Apple 사용 설명 키](https://developer.apple.com/documentation/bundleresources/information-property-list/nsmicrophoneusagedescription), [권한 요청](https://developer.apple.com/documentation/avfoundation/requesting-authorization-to-capture-and-save-media)

## 5. 메뉴바 동작 계약

| 상태/동작 | 결과 |
|---|---|
| Idle에서 좌클릭 | 권한/저장소 검사 후 즉시 Starting, 첫 오디오 수신 후 Recording |
| Recording에서 좌클릭 | Finalizing, 버퍼 배출/파일 확정 후 Idle |
| Starting/Finalizing에서 연속 클릭 | 중복 요청 무시; 진행 상태만 표시 |
| 우클릭 또는 Control-click | 녹음 패널 표시; 녹음 상태 변경 없음 |
| 패널 외부 클릭/ESC | 패널만 닫음 |
| 전사 완료 알림 클릭 | 해당 녹음 검수 창 열기 |
| 녹음 중 앱 종료 명령 | '녹음을 저장하고 종료'와 '계속 녹음' 선택 |
| 권한 거부 | 재요청 반복하지 않고 설정 안내; 가짜 녹음 상태 금지 |

UI는 NSStatusItem과 SwiftUI 호스팅 패널을 조합한다. NSStatusItem은 메뉴바 항목을 제어하는 AppKit 타입이다. [Apple](https://developer.apple.com/documentation/appkit/nsstatusitem)

정상 클릭을 가로채는 상시 `statusItem.menu` 연결은 피한다. 아이콘 자체가 녹음 명령이기 때문이다. 오른쪽 클릭은 별도 popover를 연다. `AppCoordinator`가 StatusBarController와 녹음기를 강하게 소유한다.

### 표시 사양 — 설계값

대기: 녹음 아이콘. 녹음: 정지 아이콘 + `00:24:13`. 서버 처리: 녹음 버튼 상태와 독립된 작은 작업 수 표시. 오류: 경고 모양과 접근성 문구를 함께 사용한다. 색만으로 상태를 구분하지 않는다. 경과시간은 오디오 프레임 기반으로 계산하고 1초 주기로 표시한다.

## 6. 녹음 패널

기본 폭 360pt, 콘텐츠 높이 최대 약 520pt를 출발점으로 삼는다. 작은 화면에서는 스크롤한다.

```text
Dama                            설정

녹음 중                              00:24:13
입력: 시스템 기본 마이크 · 실제 장치명
음량: [입력 레벨 표시]
제목: 2026-09-09 14:00 회의
화자 수: 자동 / 정확히 N명 / N~M명

이번 녹음 전송: 종료 후 자동 / 확인 후 / 로컬만
[ 녹음 종료 ]

처리 대기열
14:00 회의     서버 처리 중
10:30 회의     확인 필요 8곳

[ 파일 가져오기 ]                [ 모든 기록 ]
```

제목과 화자 수를 채워야 녹음할 수 있는 흐름은 금지한다. '정확한 화자 수'는 출석 인원이 아니라 **실제로 녹음에서 발화한 사람 수**를 의미하도록 안내한다. 입력 장치 선택을 아직 구현하지 않았으면 선택 가능한 것처럼 보이는 가짜 드롭다운을 넣지 않는다.

## 7. 검수 창

기본 1180×760pt, 최소 900×600pt. 폭이 줄면 오른쪽 Inspector를 접을 수 있다. 왼쪽 목록 220pt, 오른쪽 Inspector 260pt, 가운데 스크립트는 가변 폭이다. 모두 초기 UI 설계값이다.

| 영역 | 필수 요소 |
|---|---|
| 녹음 목록 | 제목/날짜/길이/처리 상태/확인 이슈 수; 같은 녹음의 실행 버전 |
| 스크립트 | 화자, 시작/종료 시간, 단어 선택, 겹침/미확정/누락 의심 배지 |
| Inspector | 현재 화자, 모델 후보, 시간 정렬 근거, 수정 명령, 이슈 설명 |
| 재생 바 | 재생/일시정지, ±3초, 속도, 위치, 원본 오디오 구간 연결 |
| 상단 | JSON/TXT 내보내기, 다음 확인 구간, 검색 |

발화를 클릭하면 기본적으로 앞 0.5초/뒤 0.5초를 포함해 재생한다. 파일 경계를 넘으면 잘라낸다. 경계 중첩을 확인할 수 있도록 구간 반복을 제공한다. 재생과 녹음이 동시에 실행될 때 재생음이 다시 녹음될 위험을 경고하고, 기본은 녹음 중 스크립트 재생 비활성화다.

**화자 이름 변경**은 해당 녹음의 화자 표시명만 바꾼다. **선택 구간의 화자 변경**은 선택한 단어들의 귀속만 바꾼다. 두 명령의 문구와 Undo 기록을 분리한다. A의 이름을 바꾸는 기능을 A 전체를 B로 병합하는 기능으로 구현하면 안 된다.

단어 선택 후 화자를 바꾸면 해당 위치에서 Turn을 재구성한다. 텍스트 수정은 자동 맞춤법 교정이 아니라 사용자의 명시적 수정만 허용한다. 자동 결과와 수정 결과를 각각 내보낼 수 있다.

## 8. 확인 필요 표시와 문구

- `ambiguous_speaker`: '화자 미확정 — 후보가 비슷합니다.'
- `overlapping_speech`: '동시에 여러 화자가 감지되었습니다. 두 사람의 발화가 모두 전사되었다는 뜻은 아닙니다.'
- `missing_speech`: '[음성 감지 / 전사 누락 의심]' — 실제 발화 텍스트로 취급하지 않는다.
- `boundary_conflict`: '단어 시간이 화자 전환 경계를 걸칩니다.'
- `capture_interrupted`: '녹음이 중단되었습니다. 이후 구간은 녹음되지 않았을 수 있습니다.'
- `result_expired`: '서버 결과를 가져오지 못했습니다. 원본은 보존되어 있습니다.'

이슈를 '확인함' 처리하는 것과 화자를 수정하는 것은 별개다. 확인해도 계속 미확정일 수 있다. '이슈 없음'을 '정확도 100%'나 '검증 완료'로 표시하지 않는다.

## 9. 원문 출력 정책

요약, 조사 보완, 문법 수정, 반복어 제거, '네/음/아' 제거, 발화자 추론을 위한 LLM 호출은 금지한다. 출력을 다른 AI에 자동 전송하지도 않는다. 사용자의 내보내기 동작만 제공한다.

원문은 녹음의 완전한 법적/음성학적 재현을 보장하는 표현이 아니라, **모델이 낸 텍스트를 임의로 요약·윤문하지 않는다**는 제품 정책이다. 모델 누락/오인식 가능성은 검수 UI와 출력 메타데이터에 남긴다.
