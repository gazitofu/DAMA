# Nemotron 3 운영 경로 확정 문구

원본은 스펙 §04 문구표다. 신규 변경은 양쪽을 함께 대조한다. 검수 이슈 6종 문구는 `review-workspace.md`·`uiux-reading.md` 확정본을 그대로 쓴다.

| 자리 | 표시 문구 | 조건 |
|---|---|---|
| Speech 엔진 제목 | Soniox 전사 + Nemotron 3 화자 분리 | `uiux-reading.md` «기본 엔진» 대체 |
| 선택 목록 | Soniox + Nemotron 3 (운영) / Soniox 단독 (비교) | Qwen·pyannote 비교는 목록에서 제외, 기존 결과 보존 |
| 엔진 이름 (스크립트 정보) | Soniox + Nemotron 3 | `EngineKind.title` |
| 화자 수 안내 | Nemotron 3에는 화자 수를 지정할 수 없습니다. 입력한 수는 스크립트 정보에서 감지 인원과 비교해 보여 줍니다. | 기본 문맥 전송 ON이면 뒤에 «Soniox에는 1~15명 힌트로 전달합니다.» |
| 화자 수 적용 | Nemotron 3 화자 수 지정 없음 · Soniox에 N명 힌트 전송 · 강제 지정 아님 / Nemotron 3 화자 수 지정 없음 · Soniox 화자 수 힌트 미전송 | 힌트 전송 여부에 따라 하나 |
| 모델 상태 | 화자 분리 모델 필요 · 약 200MB / 화자 분리 모델을 받는 중 / 화자 분리 모델 준비됨 · Nemotron 3 / 화자 분리 모델을 받지 못했습니다. 네트워크 연결을 확인한 뒤 다시 시도해 주세요. | 색이 아니라 문구로 구분, 받는 중 % 없음 |
| 모델 해시 불일치 | 받은 모델이 이 버전의 DAMA가 확인한 파일과 달라 사용하지 않았습니다. | 파일 삭제 후 «다시 받기» |
| 모델 버튼 | 모델 받기 / 다시 받기 | 누를 때만 다운로드 |
| 모델 안내 | 화자 분리는 이 Mac에서 하며 음성을 전송하지 않습니다. 모델은 처음 한 번 Hugging Face에서 받습니다. | Soniox 단독 선택 시 숨김 |
| 모델 없이 변환 | 화자 분리 모델이 없습니다. 새 전사 설정에서 모델을 먼저 받아 주세요. | 확인창 대신 표시 |
| 녹음 중 시작 차단 | 녹음 원본을 저장한 뒤 화자 분리를 시작하거나 재개해 주세요. | `allowsLocalInference` 거부 시 |
| 진행 · 실행 중 | 이 Mac에서 화자를 나누고 있습니다 / 음성을 전송하지 않습니다. 녹음을 시작하면 멈추고, 변환 재개로 처음부터 다시 실행합니다. | 단계 «전사·화자 분리» |
| 진행 · 실패 | 이 Mac에서 화자 분리를 끝내지 못했습니다 / Soniox 결과는 보존되어 있습니다. 변환 재개로 화자 분리만 다시 실행합니다. | «변환 재개» |
| 진행 · 멈춘 P2 Run | pyannote 화자 분리는 더 이상 사용하지 않습니다 / 다시 전사하면 저장된 Soniox 결과를 재사용해 Nemotron 3로 결합본을 만듭니다. | «변환 재개» 숨김, «다시 전사…»만 |
| 확인창 Nemotron 줄 | Nemotron 3: 동일 음성·모델 결과 재사용 ({Run ID}) / Nemotron 3: 이 Mac에서 화자 분리 · 음성 전송 없음 | 제목·버튼은 기존 유지 |
| 확인창 사용량 문장 | 새 Soniox 요청에만 사용량이 발생합니다. | 기존 문장의 첫 문장만 교체 |
| 확인창 화자 수 줄 | 실제 발화자 N명: Nemotron 3에는 지정하지 않음 / 실제 발화자 수 미입력 | 뒤에 기존 Soniox 힌트 문구 |

부칙: 2026-10-30 게이트 ① r1 권고안 전부 확정으로 편입.
