# 검수 창·메뉴바 문구

계획 입력 채택. 에이전트 시각 검수·앱 실물 검증 완료를 뜻하지 않는다. 원본 문구는 스펙 §04이며 아래는 동일 표의 편입본이다. 신규 변경은 양쪽을 함께 대조한다.

| 위치·상태 | 표시 문구 | 조건·동작 |
|---|---|---|
| ambiguous_speaker | 화자 미확정 · 후보가 비슷합니다. | speakerId가 null인 사실과 모델 후보는 별도 표시. |
| overlapping_speech | 동시에 여러 화자가 감지되었습니다. 두 사람의 발화가 모두 전사되었다는 뜻은 아닙니다. | 일반 diarization의 실제 겹침 근거. |
| missing_speech | [음성 감지 / 전사 누락 의심] | markerText. 인식 단어로 추가하거나 ‘네’로 채우지 않음. |
| boundary_conflict | 단어 시간이 화자 전환 경계를 걸칩니다. | 시간 충돌을 정답 화자로 오인하지 않음. |
| capture_interrupted | 녹음이 중단되었습니다. 이후 구간은 녹음되지 않았을 수 있습니다. | 보존된 실제 구간과 중단 이유를 함께 표시. |
| result_expired | 서버 결과를 가져오지 못했습니다. 원본은 보존되어 있습니다. | 원본 존재 확인 시만 후반 문장. ProcessingState.resultExpired의 UI; IssueKind에 새 enum을 넣지 않음. |
| 원본도 없음 | 서버 결과를 가져오지 못했고, 이 Mac에서 원본을 찾을 수 없습니다. | 재전사·원음 재생 비활성화. |
| unrepresented_speaker | 음성에서 감지된 화자가 스크립트에 나타나지 않습니다. | 누락 확정이 아님. |
| invalid_timestamp | 시간을 확인할 수 없습니다. 원문은 보존되어 있습니다. | 시간 null. 근처 시간으로 자동 대체하지 않음. |
| low_confidence | 공급자 화자 점수가 낮아 확인이 필요합니다. | 점수 누락에는 적용하지 않음. |
| partial_result | 일부 전사 결과를 받지 못했습니다. | words 없는 성공을 빈 정상 스크립트로 만들지 않음. |
| 근거 패널 | 현재 화자 / 모델 후보 / 공급자 화자 점수 / 시간 겹침 / 사람 확인 | confidence map은 interval별 원값. 누락은 ‘미제공’, alignmentScore는 확률이 아닌 비율. |
| 이슈 확인 | 확인함 / 미확인으로 되돌리기 | 확인 후에도 미확정 화자·marker 유지. |
| 저장 | 저장 중 / 저장됨 / 저장하지 못했습니다 / 다시 저장 / 변경 취소 | 저장 완료 전 저장됨 금지. |
| 다음 구간 | 다음 확인 구간 / 마지막 확인 구간입니다 / 첫 확인 구간으로 | open 이슈 없음: ‘미확인 이슈가 없습니다. 정확도를 보장하지는 않습니다.’ |
| 기록 없음 | 아직 녹음한 기록이 없습니다. / 메뉴바 아이콘으로 녹음을 시작하거나 파일을 가져오세요. | 파일 가져오기만 활성. 내보내기·재생 불가. |
| 검색 없음 | 검색 결과가 없습니다. / 검색어 지우기 | 녹음 목록 자체가 빈 상태와 구분. |
| 녹음 중 재생 | 녹음 중에는 재생할 수 없습니다. 재생음이 다시 녹음될 수 있습니다. | 재생·seek·반복 비활성화. |
| 권한 거부 | 마이크 접근이 꺼져 있습니다. 시스템 설정에서 다마의 마이크 접근을 허용해 주세요. | 시스템 설정 열기 / 닫기. 반복 자동 권한 요청 없음. |
| 저장소 오류 | 원본을 저장할 수 없어 녹음을 시작하지 못했습니다. | 저장 공간·권한 확인 안내. recording 표시 없음. |
| 가져오기 오류 | 파일을 가져오지 못했습니다. 원본 파일과 저장 공간을 확인해 주세요. | 원본 복사·포맷 검증 실패. 음성 전송 없음. |
| 수정 메뉴 | 선택 단어의 화자 변경 / 화자 이름 변경 / 선택 단어 수정 / 여기서 발화 나누기 / 실행 취소 / 다시 실행 | 선택 형태에 맞게 활성화. |
| 텍스트 수정 | 시간 재정렬 안 됨 / 모델 원문 보기 | editedText를 원문 text와 구분. |
| 로컬 추적 중단 | 로컬 추적 중단 / 서버 처리와 비용은 취소되지 않습니다. | 자동 서버 취소로 표현 금지. |
| 삭제 확인 | 이 Mac의 원본 삭제 / 결과 삭제 / 캐시 삭제 | 선택 항목 명시. 원본 삭제 시 ‘재전사와 원음 검수를 할 수 없습니다.’ 서버 즉시 삭제 아님. |
| 온보딩 | 마이크로 대화를 녹음하고 원본을 이 Mac에 저장합니다. / 마이크 접근 허용 / 나중에 설정 | API 키·전송 정책 설정과 별도 화면. 참석자 고지·조직 보안 정책 확인 안내. |
