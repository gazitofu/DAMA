# 스크립트 읽기·수정 화면 확정 문구

## 원문 해석에 필요한 경고

경고는 본문 옆 ‘주의’와 정보 영역에 보존한다. 검수 기록·완료 체크·오류/표본 분류·메모·타이머·검수 건수·별도 검수 목록은 UI에 표시하지 않는다. 기존 저장 기록과 원문 이슈는 삭제하지 않는다.

| 의미 | 표시 문구 | 조건 |
|---|---|---|
| ambiguous_speaker | 화자가 미확정이거나 후보가 비슷합니다. | 미배정을 추정 이름으로 채우지 않음 |
| overlapping_speech | 여러 화자의 음성 구간이 겹칩니다. 원음으로 확인해 주세요. | 두 사람의 텍스트를 모두 복구했다는 뜻이 아님 |
| missing_speech | [음성 감지 / 전사 누락 의심] | marker 보존 |
| boundary_conflict | 단어 시간이 화자 전환 경계에 걸쳐 있습니다. | 원 시간 보존 |
| capture_interrupted | 녹음이 중단되어 이후 구간이 녹음되지 않았을 수 있습니다. | 실제 중단 근거 |
| result_expired | 서버 결과를 가져오지 못했습니다. 원본은 보존되어 있습니다. | 원본 존재를 확인한 경우에만 후반 문장 |
| 원본 없음 | 이 Mac에서 원본을 찾을 수 없습니다. | 실제 로컬 원본 없음 |

기존 추가 이슈/AI 불확실성 설명은 정보 영역에 보존한다. 일반 편집 조작이 검수 완료·정답·학습 허용 기록으로 바뀌지 않는다.
