# 사용 복기 묶음 2 확정 문구

원본은 스펙 §04 문구표(번호 1–23, 19는 결번)다. 신규 변경은 양쪽을 함께 대조한다. {N}·{M}·{n}은 정수, {크기}·{전}·{후}는 `ByteCountFormatter` `.file` 표기다. 채택은 네이티브 구현·실측 완료를 뜻하지 않는다.

## 재전사 확인창 (정리 대상 N ≥ 1일 때만)

| # | 자리 | 표시 문구 | 조건 |
|---|---|---|---|
| 1 | 추가 줄 | 완료되면 이 녹음의 이전 결과 스크립트 {N}개를 휴지통으로 옮깁니다. 최근 결과 2회분과 사람이 고친 스크립트는 남깁니다. | Soniox + Nemotron 3는 «기존 수정본은 보존됩니다. …» 문단 뒤, Soniox 단독은 «새 작업으로 처리하며 …» 문단 뒤. 접수 불명 경고 앞 |
| 2 | Soniox 단독 재전사 문단 | «기존 스크립트와 사용자 수정은 유지하고 새 스크립트를 만듭니다.» → «새 스크립트를 만듭니다.» | N = 0이면 현행 |
| 3 | Soniox + Nemotron 3 문단 | «완료된 결과는 보존하고, Soniox 단독과 결합본을 따로 엽니다.» → «Soniox 단독과 결합본을 따로 엽니다.» | N = 0이면 현행 |

## 결과 저장·삭제 메시지

| # | 자리 | 표시 문구 | 조건 |
|---|---|---|---|
| 4 | 결과 저장 메시지 뒤 | 이전 결과 스크립트 {N}개를 휴지통으로 옮겼습니다. | 실제로 옮긴 수 ≥ 1 |
| 5 | 결과 저장 메시지 뒤 | 이전 결과 스크립트 {M}개는 옮기지 못해 그대로 두었습니다. | 못 옮긴 수 ≥ 1 |
| 6 | Script 삭제 확인창 설명 | 선택한 스크립트 파일을 휴지통으로 이동하고, 이 스크립트의 내부 수정 이력과 AI 버전 기록을 지웁니다. 파일을 휴지통에서 되돌려도 지운 AI 버전은 열 수 없습니다. 연결된 Speech·다른 Scripts·내보낸 Markdown과 원음·전사 원응답은 남습니다. | 현행 «… 내부 복구 이력은 남습니다.» 대체. 공통 끝 문단·버튼·기본 «취소»는 현행 |
| 7 | Script 삭제 완료 메시지 뒤 | 내부 수정 이력은 지우지 못했습니다. 설정의 저장 공간 정리에서 다시 지울 수 있습니다. | 이력 삭제 실패. 이때 현행 뒷문장 «원음과 다른 스크립트는 유지됩니다.»는 뺀다 |

## 설정 · 저장 공간

| # | 자리 | 표시 문구 | 조건 |
|---|---|---|---|
| 8 | 절 머리 | 저장 공간 | 폴더 절과 API 키 절 사이 |
| 9 | 절 설명 | 스크립트 파일과 내부 수정 이력을 정리합니다. 녹음 원음과 전사 원응답은 지우지 않습니다. | 항상 |
| 10 | 버튼 · 크기 줄 | 저장 공간 정리… / 내부 수정 이력 {크기} | 크기 = 설정을 열 때 `LibraryRevisions` 아래 파일 크기 합 |
| 11 | 버튼 꺼짐 안내 | 다른 작업이 끝난 뒤 정리할 수 있습니다. | 변환·AI 교정·녹음 마무리·편집 중이거나 Scripts 목록을 읽는 중 |
| 12 | 확인 중 · 확인창 제목 | 정리할 항목을 확인하는 중… / 저장 공간을 정리할까요? | |
| 13 | 확인창 줄 · 스크립트 | 이전 결과 스크립트 {N}개 · {크기}를 휴지통으로 옮깁니다. 녹음마다 최근 결과 2회분과 사람이 고친 스크립트는 남깁니다. | N ≥ 1 |
| 14 | 확인창 줄 · 지울 이력 | 현재 Scripts 폴더에 없는 스크립트의 내부 수정 이력 {N}개 · {크기}를 지웁니다. | N ≥ 1, Scripts 조회 문제 없음 |
| 15 | 확인창 줄 · 지울 이력 대신 | Scripts 폴더에 읽지 못한 파일이 있어 내부 수정 이력 삭제는 건너뜁니다. | Scripts 조회에 파일별 문제 |
| 16 | 확인창 줄 · 압축 | 내부 수정 이력 {N}개 · {크기}를 압축합니다. 압축을 푼 내용이 원본과 같을 때만 원본을 지웁니다. | N ≥ 1 |
| 17 | 확인창 줄 · 시도 기록 | 현재 Scripts 폴더에 없는 스크립트의 AI 교정 시도 기록 {N}개를 지웁니다. | N ≥ 1, Scripts 조회 문제 없음 |
| 18 | 확인창 끝줄 · 버튼 | 지운 수정 이력은 되돌릴 수 없습니다. 녹음 원음과 전사 원응답은 지우지 않습니다. / 취소 / 정리 | 기본 버튼 «취소» |
| 19 | (결번) | | D-01 기각안용 |
| 20 | 진행 | 저장 공간을 정리하는 중… ({n}/{N}) | {N} = 확인창 항목 수 합 |
| 21 | 완료 | 저장 공간을 정리했습니다. 내부 수정 이력 {전} → {후}. + 이전 결과 스크립트 {N}개를 휴지통으로 옮겼습니다. + 처리하지 못한 파일 {M}개는 그대로 두었습니다. | 둘째 문장은 스크립트 ≥ 1, 셋째 문장은 실패 ≥ 1 |
