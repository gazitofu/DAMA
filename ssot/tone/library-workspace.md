# 폴더·스크립트 화면 문구

이번 화면의 문구는 아래를 우선한다. 기존 review-workspace의 이슈 의미·원문 보존 규칙은 유지한다. 채택은 네이티브 화면의 실측 완료를 뜻하지 않는다.

| 위치 | 표시 문구 | 동작·조건 |
|---|---|---|
| 앱 | DAMA | 한국어 명칭 다마, 기술 식별자 유지 |
| 하단 폴더 | Speeches / Scripts | 녹음·최종 스크립트, 중간 폴더 없음 |
| 폴더 드롭다운 | 폴더 선택… / Finder에서 열기 | 각각 위치 지정·선택한 위치 열기 |
| 목록 | 최신순 / 변환필요 / 변환완료 | 필요 빨강·완료 초록, 완료 시 연결 스크립트 열기 |
| 변환 입력 | 총 참여 화자 수 / 맥락 / 참고 정보 | 비워 두면 자동으로 판단합니다. |
| 참고 메모 | 맥락·참고 정보는 로컬 참고 메모이며 Markdown 내보내기에 포함됩니다. | 입력과 공급자 API 전달 범위를 혼동하지 않음 |
| 변환 | 정보 저장 / 변환 / 변환 재개 / 스크립트 저장 | 현재 저장·처리 단계에 맞게 표시 |
| 스크립트 | 스크립트 / 녹음·변환 정보 / 내보내기 | 제목 수정 가능, 내보내기 한 동작으로 .md 저장 |
| 화자 이름 | 이 부분만 바꾸기 / 이 부분부터 바꾸기 / 전체 바꾸기 | 원 화자 ID 기준, from은 현재 발화 포함 |
| 편집 | 저장 / 취소 / 사용자 수정 · 시간 재정렬 안 됨 | 모델 원문·시간은 보존 |
| 메뉴바 | 녹음 시작 / 녹음 중 / Open DAMA / DAMA Version info / Quit DAMA | 녹음 토글과 세 메뉴, 실제 녹음 중에만 빨간 아이콘 |
| 처리 단계 | 음성 전송 / 작업 접수 / 전사·화자 분리 / 스크립트 저장 | 실제 단계만 표시, 단계 번호를 작업 완료율로 환산하지 않음 |
| 서버 상태 | 서버에서 처리 순서를 기다리고 있습니다 / 전사와 화자 분리가 진행 중입니다 | pending·created와 running 구분 |
| 처리 시간 | 이번 처리 경과 / 마지막 서버 확인 | 현재 재개 세션 경과와 실제 마지막 정상 응답 시각, ETA·% 없음 |
| 연결·중단 | 네트워크 연결 확인이 필요합니다 / 처리 상태 확인이 멈춰 있습니다 | 스피너 중단, 서버 작업 취소로 오인시키지 않음 |
| 결과 저장 | 전사 완료 · 스크립트 저장이 필요합니다 / 변환이 완료되었습니다 | 외부 스크립트 파일이 확인된 뒤에만 저장 단계 완료 |
| 이벤트 | 이 구간의 이벤트 / 닫기 | open 이슈가 있을 때만 화자 옆 노란 느낌표로 열기. ‘확인할 내용’ 상시 행 제거 |

추가4항은 사용자 실사용 수정 지시(2026-09-10)로 반영. 화자 색과 연속 문단을 추가하며 원 Turn·단어·검수 이슈를 삭제하지 않는다.
