# 사용 복기 묶음 1 확정 문구

원본은 스펙 §04 문구표(번호 1–22)다. 신규 변경은 양쪽을 함께 대조한다. 이 파일은 `uiux-reading.md`의 같은 자리 문구(경고 표시 원칙, 제목 저장, AI 실패)보다 우선한다. 채택은 네이티브 구현·실측 완료를 뜻하지 않는다.

## 검수 이슈 표시

| 자리 | 표시 문구 | 조건 |
|---|---|---|
| 경고 줄 (문단 아래·구간 정보 맨 위) | 녹음이 중단되어 이후 구간이 녹음되지 않았을 수 있습니다. / 일부 전사 결과를 받지 못했습니다. | `capture_interrupted` / `partial_result`. 항상 표시, ⚠ 기호와 함께 |
| 문단 이름 옆 | (없음) | «주의» 버튼 제거, 설정으로 다시 켜지 않음 |
| 구간 정보 접힘 | 자동 경고 {N}건 | 자동 경고 8종, 기본 닫힘, 0건이면 줄 없음 |
| 구간 정보 접힘 안내 | 화자 분리와 시간 정렬이 남긴 자동 판정입니다. 원음으로 확인한 결과가 아닙니다. | 펼쳤을 때 첫 줄 |
| 구간 정보 종류 행 | {종류 문구} · {N}건 | 건수 내림차순, 같으면 종류 이름 오름차순 |
| ambiguous_speaker | 화자가 미확정이거나 후보가 비슷합니다. | uiux-reading 확정본 |
| overlapping_speech | 여러 화자의 음성 구간이 겹칩니다. 원음으로 확인해 주세요. | uiux-reading 확정본 |
| missing_speech | [음성 감지 / 전사 누락 의심] | 유지 |
| boundary_conflict | 단어 시간이 화자 전환 경계에 걸쳐 있습니다. | uiux-reading 확정본 |
| unrepresented_speaker | 음성에서 감지된 화자가 스크립트에 나타나지 않습니다. | 유지 |
| invalid_timestamp | 시간을 확인할 수 없습니다. 원문은 보존되어 있습니다. | 유지 |
| low_confidence | 공급자 화자 점수가 낮아 확인이 필요합니다. | 유지 |
| provider_disagreement | 제공자 간 화자 구분 충돌 | 현행 코드 유지 |
| result_expired | 서버 결과를 가져오지 못했습니다. 원본은 보존되어 있습니다. | 이 유닛 화면 밖, 변경 없음 |

## Markdown

| 자리 | 문구 | 조건 |
|---|---|---|
| 머리말 검수 줄 | `- 검수: 자동 화자 분리 결과이며 사람이 원음으로 검수하지 않음. 자동 경고 {N}건({이름} {n}, …)은 생략` | 원음 확인 기록 0건. 기존 `- 검수:` 자리 |
| 머리말 검수 줄 (경고 0) | `- 검수: 자동 화자 분리 결과이며 사람이 원음으로 검수하지 않음. 자동 경고 0건 (경고 없음이 정확도를 보장하지 않음)` | |
| 머리말 검수 줄 (원음 확인 있음) | `- 검수: {현행 요약}. 자동 경고 {N}건({이름} {n}, …)은 생략` | |
| 종류 짧은 이름 | 화자 경계 걸침 / 겹침 / 시간 불명 / 제공자 화자 불일치 / 누락 의심 / 본문에 없는 화자 / 화자 미확정 / 낮은 화자 점수 | boundary_conflict / overlapping_speech / invalid_timestamp / provider_disagreement / missing_speech / unrepresented_speaker / ambiguous_speaker / low_confidence 순. 천 단위 쉼표 |
| 머리말 중단·일부 결과 | `- 녹음 중단: 녹음이 중단되어 이후 구간이 녹음되지 않았을 수 있습니다.` / `- 일부 결과: 일부 전사 결과를 받지 못했습니다.` | 해당 이슈가 있을 때 |
| 문단 아래 | `> 녹음 중단: …` / `> 일부 결과: …` | 같은 문장. 문단별 `> 검수:` 줄은 쓰지 않음 |

| 스크립트 제목 캡션 | 녹음 제목과 같이 바뀝니다. | 연결 녹음이 있을 때만 |

## AI 교정 실패·이어하기·의미 보호

| 자리 | 표시 문구 | 조건 |
|---|---|---|
| 하단 미완료 줄 | AI 보정 미완료 · {k}/{n} 구간 완료 · {짧은 원인} | 시도 기록 있음, 실행 중 아님 |
| 짧은 원인 | 취소함 / 실행 불가 / 시간 초과 / 로그인 필요로 보임 / 연결 문제로 보임 / 설정 거부 / 응답 형식 불일치 / 원인 미분류 (종료 코드 {N}) | 분류 8종 |
| 버튼 | 이어서 교정 ({k}/{n}) / 같은 입력으로 다시 시도 | 후자는 완료 0개 |
| 이어하기 불가 | 스크립트가 바뀌어 이어서 교정할 수 없습니다. AI 검수/보정으로 처음부터 다시 실행해 주세요. | 청크 계획·엔진 불일치 |
| 확인창 | 이어서 교정할까요? (같은 입력으로 다시 시도할까요?) / 완료한 {k}개 구간은 다시 보내지 않습니다. 남은 {m}개 구간의 전사와 처음 확인한 참석자·맥락·참고 내용을 OpenAI로 전송합니다. 계정 사용량이 소모될 수 있습니다. 원음은 보내지 않습니다. / (완료 0개 첫 문장) 처음 확인한 입력으로 {n}개 구간 전부를 다시 보냅니다. / 취소 / 이어서 교정 (다시 시도) | 기본 버튼 «취소» |
| 실패 안내 띠 · 실행 불가 | Codex를 실행하지 못했습니다. 설정에서 Codex 실행 파일을 확인해 주세요. 기존 결과는 유지됩니다. | |
| 실패 안내 띠 · 인증 | Codex 로그인이 필요해 보입니다. 터미널에서 Codex에 로그인한 뒤 이어서 교정해 주세요. 기존 결과는 유지됩니다. | 표식 추정 |
| 실패 안내 띠 · 네트워크 | 연결 문제로 보입니다. 네트워크를 확인한 뒤 이어서 교정해 주세요. 기존 결과는 유지됩니다. | 표식 추정 |
| 실패 안내 띠 · 설정 | Codex가 실행 설정을 받아들이지 않았습니다. Codex 버전이 바뀌었을 수 있습니다. 기존 결과는 유지됩니다. | |
| 실패 안내 띠 · 시간 초과 | 한 구간이 300초 안에 끝나지 않았습니다. 이어서 교정으로 그 구간부터 다시 보낼 수 있습니다. 기존 결과는 유지됩니다. | |
| 실패 안내 띠 · 형식 | AI 응답이 요구한 형식과 맞지 않아 쓰지 않았습니다. 이어서 교정으로 그 구간부터 다시 보낼 수 있습니다. 기존 결과는 유지됩니다. | |
| 실패 안내 띠 · 미분류 | AI 보정을 완료하지 못했습니다. 종료 코드 {N}. 기존 결과는 유지됩니다. | `uiux-reading.md` «AI 실패» 대체 |
| 실패 안내 띠 · 취소 | AI 보정을 취소했습니다. 기존 결과는 유지됩니다. (+ 완료한 구간은 이어서 교정에 남아 있습니다.) | 완료 구간이 있을 때 덧붙임 |
| AI 검수/보정 창 | 미완료 교정({k}/{n})은 버리고 처음부터 다시 보정합니다. | 시도 기록이 있을 때 전송 고지 위 |
| 의미 보호 보류 근거 | {분류} 표현이 바뀌는 수정이라 자동 반영하지 않았습니다. 원음으로 확인해 주세요. | 분류 = 숫자·단위·부정·조건 중 바뀐 것 |

## 설정

| 자리 | 표시 문구 | 조건 |
|---|---|---|
| API 키 | Soniox API 키 | 서비스 선택 없음 |
| pyannote 줄 | 저장된 pyannote API 키가 있습니다. pyannote는 더 이상 사용하지 않습니다. / pyannote 키 삭제 | 키체인에 항목이 있을 때만 |
| pyannote 삭제 확인 | 이 Mac의 pyannote API 키를 삭제할까요? / pyannote는 더 이상 사용하지 않습니다. 녹음 원본·스크립트·이미 만든 pyannote 결과는 유지됩니다. / 취소 / 키 삭제 | 기본 버튼 «취소» |

| 월 비용 안내 | pyannote 항목은 세 칸을 모두 입력해야 합계에 넣습니다. | 퇴역 1–2칸만 입력 |
